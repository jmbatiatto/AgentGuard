# Galería Interactiva de Arquitectura y Modelado (27 Diagramas)

Los **27 diagramas técnicos** de esta galería se extraen y sincronizan automáticamente a partir de los volúmenes verificados de `documentación final/` (arquitectura Zero Trust PEP/PDP, modelo relacional de **13 tablas PostgreSQL 16 + caché Redis 7 + 7 tablas SQLite ACME**, notación conceptual Chen, máquinas de estado HITL, secuencias de los 4 escenarios canónicos, vistas React 19 y flujo multi-turno con Handshake Universal Multi-LLM: Gemini 2.5 Flash, OpenAI, Groq y Anthropic).

::: tip Exportación en máxima nitidez para decks ejecutivos, revisiones técnicas y proyector en vivo
- **Presentaciones ejecutivas y revisiones de arquitectura:** usá **Descargar SVG Vectorial** (escalabilidad infinita) o **PNG 4K Oscuro**, renderizado sobre fondo *Dark Navy* (`#0b1120`) para integrarse con la identidad visual de AgentGuard. También disponés de **PNG 4K Claro** para informes impresos y documentos técnicos.
- **Modo proyector interactivo en vivo:** hacé clic en **Proyector Interactivo** en cualquier tarjeta para abrir el visor a pantalla completa con zoom mediante rueda del mouse (`0.25x` a `8x`) y desplazamiento libre (*pan*), o navegá directo al [Índice Maestro SSOT](/volumenes/INDICE_MAESTRO) donde se documenta cada diagrama.
- **¿Preferís un recorrido guiado en 68 segundos?** Mirá el [Video Demo Oficial (68s)](https://drive.google.com/file/d/1MGKSaJY939cJWj5cr5Wl7op8VL1b91c5/view?usp=drivesdk) o ingresá al [Kit de Presentación & QR](/modo-presentacion).
:::
